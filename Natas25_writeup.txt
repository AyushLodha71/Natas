Simple 5 Steps of execution:

1. Trigger — lang contains ../, which fires the traversal-detection branch
2. Plant — that branch logs your User-Agent (your PHP payload) into a file
3. Execute — the same code path then include()s that same file, running your payload
4. Feed — your now-running code reads cmd from the URL
5. Output — the command runs, result shows up in the response
